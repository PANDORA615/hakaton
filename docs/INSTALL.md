# Установка Aéza Retention v1.0

Нужны Docker Engine или Docker Desktop с Linux containers, Docker Compose v2, Git и свободный порт 8080. Для ручной настройки Python и Node.js не нужны.

## Запуск

1. Получите код: `git clone https://github.com/PANDORA615/hakaton.git`, затем `cd hakaton` и `git checkout v1.0`.
2. Создайте приватный `.env`: `python3 scripts/init_env.py` (Windows: `py scripts/init_env.py`). Скрипт показывает пароль администратора один раз. Если Python отсутствует, скопируйте `.env.example` в `.env` и задайте `POSTGRES_PASSWORD`, `ADMIN_PASSWORD` (от 12 символов), `METRICS_TOKEN`. Пароль БД должен состоять из латинских букв и цифр. Никогда не коммитьте `.env`.
3. Запустите `docker compose up -d --build` и проверьте `docker compose ps`.
4. Откройте <http://localhost:8080/>. Логин: `admin`; пароль: из шага 2. При первом запуске миграции создают таблицы и исходный набор импортируется один раз. Повторный запуск сохраняет данные и настройки.
5. Проверьте <http://localhost:8080/healthz> (ожидается `{"status":"ok"}`). Без входа `/api/v1/customers` возвращает 401. Swagger доступен после входа по `/api/v1/docs`.

## Сотрудники

Администратор открывает аватар → «Настройки аккаунта» → «Сотрудники» и создаёт отдельный логин. Сотрудник работает с клиентами и результатами; модель и импорт меняет только администратор. Передайте временный пароль приватно. Администратор может отключить сотрудника или сбросить его пароль; действующие сеансы тогда отзываются. Демонстрационный OIDC через Dex входит в учётную запись администратора.

## Демонстрация и данные

`ANALYSIS_AS_OF=2026-10-19T15:00:00Z` фиксирует время кейса; пустое значение включает live UTC. В live-режиме источник должен поставлять актуальные снимки. Демоданные добавляются отдельно и имеют метку `demo-`. Score — индекс, деньги под риском — сценарная оценка; вручную подтверждённая сумма показывается отдельно. [Сценарий показа](demo.md).

## Обновление и безопасность

Перед обновлением сохраните базу: `docker compose exec -T db pg_dump -U retention -Fc retention > retention-backup.dump`. Проверьте архив: `docker compose exec -T db pg_restore --list < retention-backup.dump`. Затем получите нужный тег и выполните `docker compose up -d --build`. Alembic запускается при старте backend. Проверять восстановление следует в отдельной БД; полная процедура и откат — в [инструкции выпуска](deploy.md).

Обычный Compose слушает `127.0.0.1:8080`. Для других устройств нужны HTTPS-прокси, домен и `COOKIE_SECURE=true`. Настройка Dex/Caddy описана в [OIDC-инструкции](hackathon-oidc.md); секреты не входят в Git.

## Диагностика

- Состояние: `docker compose ps`; ошибки: `docker compose logs --tail=100 backend`.
- Порт занят: измените `APP_PORT` в `.env`.
- Изменение `ADMIN_PASSWORD` в `.env` не меняет уже созданный пароль администратора.
- Даты и ошибки обновления тарифов видны в конкурентном радаре. Мониторинг может читать `churn_tariff_failed_sources` в защищённом `/metrics`.
