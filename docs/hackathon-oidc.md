# OIDC для хакатона без внешнего провайдера

Проверка протокола: `bash scripts/check_oidc_hackathon.sh`. Команда собирает отдельный backend-образ и запускает тест без сети. Тест генерирует временный подписанный ID-токен, проверяет PKCE S256, `state`, `nonce`, выдачу локальной сессии, запрет повторного callback и отклонение неверного `nonce`. Рабочие контейнеры и база не меняются.

Показ в браузере: встроенный Dex работает как демонстрационный OIDC-провайдер. Откройте HTTPS-сайт, нажмите «Войти через единый вход», войдите в тестовую учётную запись Dex и вернитесь в приложение. Это реальный OIDC-переход, но без внешнего корпоративного провайдера. Учётные данные для показа хранятся вне Git в `.runtime/oidc-credentials.txt` на сервере.

Dex и парольный вход приложения независимы. После проверки ID-токена приложение допускает только один разрешённый `sub` и создаёт локальную сессию администратора. Почта и имя из токена не дают доступ. Для корпоративного внедрения потребуются отдельные аккаунты сотрудников и явная привязка `(issuer, sub)` к каждому.
